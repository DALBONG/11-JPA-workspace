th:object - 폼이 어떤 객체와 연결될지 알려줌.
  -> 해서 컨트롤러 단에 셋팅을 해줘야 함.
     model.addAttribute("memberForm", new MemberForm());

       이후, *{name}, *{city} 이런 식으로 접근 가능.
       (멤버폼 객체를 이 폼에서 기본 객체로 쓰겠다는 뜻)

th:field  - 폼 입력 값을 객체의 필드에 자동으로 연결.

    ex)
    <input type="text" th:field="*{city}" class="form-control" placeholder="도시를 입력하세요">
    == <input type="text" id="city", name="city" class="form-control" placeholder="도시를 입력하세요">
    이렇게 자동으로 연결해줌.
    만약, memberForm.getName이 김달봉이면, value로 연결. 없으면 ""
